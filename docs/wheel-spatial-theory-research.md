# 轮盘空间打法研究起点

更新时间：2026-06-13  
状态：研究起点文档，先记录成熟理论与可验证方向，尚未产品化。

## 1. 研究背景

这次研究先暂时放下已有的 124、热门、追6、长套等具体方案，重新从真实轮盘的物理布局出发。

欧洲轮盘 37 个号码在轮盘上一圈的顺序是固定的，不是按桌面上的 1-36 顺序排列。真实落球如果存在机械偏差、荷官习惯、桌台状态、球速/盘速组合、局部磨损或其他非随机因素，它可能首先表现为空间区域上的偏热或偏冷，而不一定表现为某一个单号长期偏热。

因此，本研究的核心问题是：

1. 落球是否在真实轮盘空间上存在可重复的区域偏差？
2. 如果存在，这种区域偏差是否能比单纯热门号码更稳定？
3. 是否能用空间信号改进现有方法，或者发展出一个新的“轮盘区域”打法？
4. 2026 年 4、5、6 月这批同赌场数据中，是否存在更明显的空间痕迹？

## 2. 成熟理论的基本结论

### 2.1 传统资金递增法不能创造优势

典型例子包括 Martingale、D'Alembert、Fibonacci、Labouchere、Paroli 等。

这些方法本质上只改变资金曲线形状：

- 可能提高短期小赢的概率。
- 会把风险集中到少数大亏局。
- 不能改变轮盘单次下注的数学期望。
- 在有桌限和本金限制时，长尾风险会非常明显。

对本项目的启发：

- 1-2-4、1-2-3-5、1-2-4-8 等不应该被视为“优势来源”。
- 它们只能作为资金管理和风险分布工具。
- 真正需要研究的是：什么时候下注、下注哪些号码、什么时候退出。
- 任何新方法都必须单独统计最大回撤、连亏段、单局分布，不能只看总 ROI。

### 2.2 成熟的可行优势主要来自非随机性

现实中相对成熟的轮盘优势思路，通常不来自“赌法公式”，而来自轮盘或落球过程的非随机性：

- 轮盘偏差：某些号码或某些区域因为机械原因更容易出现。
- 区域偏差：单个号码未必稳定，但一段相邻轮盘号码可能整体偏热。
- Visual ballistics：观察球速、盘速、释放点、落点区域，预测大致区域。
- 荷官/桌台节奏：同一赌场、同一桌、同一荷官，可能有局部稳定性。

对本项目的启发：

- 我们目前只有号码序列，没有球速/盘速/释放点，所以无法完整复刻 visual ballistics。
- 但我们可以研究结果序列在真实轮盘空间上的聚集、迁移、持续和反转。
- 这比只看桌面行/组更接近真实落球物理过程。

### 2.3 热门/冷门不能按“赌徒谬误”理解

如果轮盘完全随机，热门和冷门本身不应产生优势。

但如果我们把热门/冷门当成“偏差证据”，就有研究价值：

- 热门不是因为“热所以必然继续热”，而是因为它可能暴露了某种局部非随机性。
- 冷门不是因为“欠了所以该出”，而是可能提示区域轮动、偏差反转或当前区域失效。
- 单号热门噪声很大，区域热门可能更稳。

对本项目的启发：

- 热门号码算法可以引入轮盘邻号/区域聚合。
- 不要只问“某号是否热”，还要问“它所在轮盘区域是否热”。
- 如果单号热但所在区域不热，信号可能较弱。
- 如果多个相邻轮盘号码共同偏热，信号可能更值得研究。

### 2.4 Kelly 思想适合做下注强度，而不是做信号

Kelly Criterion 的核心是：当有真实正期望时，按优势大小决定下注比例。

对本项目的启发：

- Kelly 不能帮助我们找到优势，只能帮助我们控制投注规模。
- 如果未来某个区域信号被证明有正期望，可以用半 Kelly 或更保守的分数 Kelly 作为资金管理参考。
- 在项目当前阶段，更重要的是先验证信号是否真实存在。

## 3. 欧洲轮盘空间模型

欧洲轮盘常用顺序：

```text
0,32,15,19,4,21,2,25,17,34,6,27,13,36,11,30,8,23,10,5,24,16,33,1,20,14,31,9,22,18,29,7,28,12,35,3,26
```

建立映射：

- `wheelIndex[number] = 0..36`
- 两个号码的轮盘距离：

```text
distance(a, b) = min(abs(indexA - indexB), 37 - abs(indexA - indexB))
```

空间区域可以有几种定义：

1. 固定中心 + 半径：例如中心号左右各 2 个，共 5 个号。
2. 固定弧段：把 37 个位置切成若干段，例如 5/7/9 个一组。
3. 动态热区：滚动窗口里分数最高的一段连续轮盘区域。
4. 双热区：一局中可能存在两个相隔较远的热点区域。
5. 迁移热区：热点中心随时间缓慢移动。

## 4. 最值得优先验证的方向

### 4.1 轮盘区域热度

基础想法：

- 用最近窗口统计每个轮盘连续区域的出现次数。
- 例如每个中心号取左右各 2 个，一共 5 个号。
- 对 37 个中心分别计算区域命中数。
- 选择分数最高且显著高于随机期望的区域。

随机期望：

```text
窗口长度 = W
区域大小 = K
期望命中 = W * K / 37
```

可以计算：

- `obs`: 实际命中数
- `expected`: 随机期望
- `excess = obs - expected`
- `ratio = obs / expected`
- `z = (obs - expected) / sqrt(W * p * (1 - p))`, `p = K / 37`

下注方式候选：

- 只押最强 5 号区域。
- 只押最强 7 号区域。
- 如果最强区域和次强区域接近，不下注。
- 如果最强区域过度分散，不下注。

关键验证：

- 5 号区域信号 ROI 是否比单号热门更稳。
- 7 号区域是否降低波动但稀释收益。
- 区域大小 K 是否应根据波动频率自适应。

### 4.2 区域持续与区域反转

空间热门不一定一直持续，也可能阶段性反转。

需要区分：

- 持续型：热区命中后，附近区域继续容易出。
- 反转型：热区过热后，下一阶段转向对侧或相邻冷区。
- 扩散型：中心热区逐渐向两边扩散。
- 跳跃型：热区在几个固定区域之间切换。

可测试指标：

- 当前热区最近 20/37/74 口命中率。
- 热区中心在连续窗口中的移动距离。
- 热区命中后的下一口落点距离分布。
- 热区连续未命中后是否更容易反转。

策略候选：

1. 热区持续：热区强且中心稳定时，追当前热区。
2. 热区衰竭：热区过热但近期命中率快速下降时，暂停。
3. 热区迁移：中心连续向同方向移动时，押前方区域。
4. 热区反转：热区连续失败达到阈值后，押对侧或历史次强区。

### 4.3 轮盘邻号改进热门号码

已有热门号码算法可以加入空间邻域：

- 单号热度：号码本身最近出现情况。
- 邻号热度：该号码左右邻号区域的整体出现情况。
- 区域集中度：热号是否聚在真实轮盘相邻区域。
- 区域一致性：热门号码的 topN 是否落在同一段弧上。

候选评分：

```text
score(number)
  = a * ownHotScore
  + b * neighborSectorScore
  + c * recentTrendScore
  - d * overfitPenalty
```

重要判断：

- 如果热门 topN 在轮盘上高度分散，可能只是随机噪声。
- 如果热门 topN 聚成一段，可能是区域偏差证据。
- 如果热门号码和空间热区一致，可以提高信号等级。
- 如果热门号码与空间热区冲突，可以降低或跳过信号。

### 4.4 轮盘空间 Markov

传统 Markov 看的是“上一个数字之后，下一个数字更容易是什么”。

空间 Markov 应该改成：

- 上一口落在某个区域。
- 下一口相对上一口在轮盘上偏左、偏右、附近、对侧的概率。

可定义相对位移：

```text
delta = signedCircularDistance(prevIndex, nextIndex)
```

然后统计：

- `delta = -2..+2` 是否偏高。
- 是否存在固定偏移，例如上一口之后下一口常落在顺时针 8-12 格。
- 是否只在某些赌场/日期/阶段有效。
- 位移分布是否随时间变化。

策略候选：

- 上一口为中心，押相对高频位移对应的 5 个号。
- 根据最近窗口动态选择偏移中心。
- 如果位移分布过散，不下注。

### 4.5 空间信号与录号区/押注区

本项目真实使用时，经常前 200 口是录号区数据，后面才是押注区数据。

空间研究应保持统一口径：

- 录号区数据可以作为信号上下文。
- ROI 要分别统计全部数据 ROI 和押注区数据 ROI。
- 重点看押注区数据表现。
- 对有前 200 口的局，额外考察“前 200 口空间状态”能否预测后续质量。

可能有效的过滤：

- 前 200 口已有明显空间热区，后续只启用区域打法。
- 前 200 口空间分散，后续不启用或降低信号等级。
- 前 200 口不好但最后 37/20 口转强，则允许启用。
- 前 200 口强但最后 37/20 口明显衰退，则暂停。

## 5. 必须避免的研究陷阱

### 5.1 多参数过拟合

空间研究很容易产生大量参数：

- 窗口长度 W
- 区域大小 K
- z-score 阈值
- 热区稳定性阈值
- 近期趋势阈值
- 下注轮数
- 是否反转
- 是否结合热门

如果只挑历史上最漂亮的一组，会非常危险。

必须做：

- walk-forward 回测。
- 最近 10 局、最近 3 局单独看。
- 按年、按月份、按赌场/数据来源拆开看。
- 看最大回撤和负收益局分布。
- 与随机轮盘顺序或打乱顺序做对照。

### 5.2 不能只看总 ROI

一个策略可能靠少数大赢局拉高总 ROI。

每次研究输出至少要包括：

- 总信号数
- 总下注额
- 命中次数
- 净收益
- ROI
- 胜率
- 最大回撤
- 正收益局数量
- 负收益局数量
- 最近 10 局表现
- 最近 3 局表现
- 每局净收益分布

### 5.3 要区分号码频率优势和空间优势

如果一个方法只是押热门号码，即使套上轮盘空间，也不一定证明空间有效。

需要做对照：

1. 原号码顺序下的空间策略。
2. 随机打乱轮盘号码位置后的同策略。
3. 只用单号热门，不用空间。
4. 只用空间区域，不用单号热门。
5. 单号热门 + 空间一致性过滤。

如果原轮盘顺序显著优于随机打乱顺序，才说明空间信息可能真的有用。

## 6. 第一批实验设计

### 实验 A：固定区域热度

目标：验证真实轮盘连续区域是否有可押价值。

参数网格：

- 窗口：37、74、111、148、200
- 区域大小：5、7、9
- 阈值：z >= 1.0、1.25、1.5、1.75、2.0
- 下注：只追下一口

输出：

- 全部数据 ROI
- 押注区 ROI
- 最近 10 局
- 最近 3 局
- 每局分布
- 最大回撤

### 实验 B：区域热度 + 稳定性

目标：避免短期随机聚集。

新增条件：

- 最近两个窗口的最强中心距离 <= 2。
- 最近 37 口和最近 74 口同方向支持。
- 最强区域与次强区域差距达到阈值。

候选：

```text
sectorScore37 >= threshold
sectorScore74 >= threshold
centerDrift <= 2
top1MinusTop2 >= gapThreshold
```

### 实验 C：区域热度 + 热门号码交集

目标：押更少但更精准。

候选：

- 先找空间热区。
- 再找热门号码 topN。
- 只押二者交集。
- 如果交集少于 2 个或多于 6 个，不下注。

需要比较：

- 信号减少多少。
- ROI 是否提高。
- 均匀度是否提高。
- 最近局是否更稳定。

### 实验 D：不减少信号的空间加权热门

目标：不牺牲频率，用空间调整排序。

做法：

- 仍然输出固定数量候选号码。
- 热门分数加入轮盘邻域分。
- 如果空间强，则优先选空间热区内号码。
- 如果空间弱，则退回原热门逻辑。

这是更适合产品化的方向，因为 Wayne 明确多次强调：有些优化不能明显减少信号。

### 实验 E：空间 Markov 位移

目标：研究上一口到下一口的轮盘相对位移是否有偏差。

做法：

- 把每口转换成 wheelIndex。
- 统计最近窗口内 `prev -> next` 的 signed delta。
- 找出高频 delta 区间。
- 下一口押上一口加上高频 delta 附近的区域。

需要特别防止过拟合，因为 delta 有 37 种可能，参数空间很大。

### 实验 F：空间状态切换

目标：不是固定用一种方案，而是根据当前空间状态切换。

状态候选：

- `spatial-hot`: 区域热度强且稳定，追热区。
- `spatial-drift`: 热区中心移动明显，追迁移方向。
- `spatial-chaos`: 区域分散，不下注或退回其他方法。
- `spatial-reversal`: 热区过热后衰竭，尝试反向。

状态指标：

- 区域 z-score。
- 热区中心漂移。
- 热区集中度。
- 最近命中/未命中节奏。
- 最近 20/37 口相对前 74/148 口的变化。

## 7. 与现有功能的关系

### 热门号码

最可能被空间研究直接改进。

可尝试：

- 热门号必须得到轮盘邻域支持。
- 热门号排序加入空间邻域分。
- 热门号如果集中在同一轮盘区域，提高信号等级。
- 热门号如果完全分散，降低或暂停。

### 行组节奏

行组节奏是桌面布局的行/组节奏，不是真实轮盘空间。

可尝试：

- 保持行组节奏本身不变。
- 只研究当行组节奏出信号时，目标号码在轮盘空间上是否支持。
- 如果行组节奏目标区与空间热区冲突，降低信号或不下注。

### 追6 / 长套

这些方法本质上与桌面分组和遗漏有关。

可尝试：

- 出现追6/长套信号时，检查对应号码集合是否在轮盘空间上过于分散。
- 如果空间上有明显支持，保留。
- 如果空间状态混乱，降低权重。

### 单号重号

重号和短重号此前已被性能暂停或隐藏，但空间上仍可研究：

- 重号是否更容易发生在某些空间热区内。
- 某个空间区域热时，区域内的重号/隔一重是否增加。

## 8. 第一阶段推荐路线

优先顺序：

1. 写独立研究脚本，不动产品逻辑。
2. 实现欧洲轮盘 wheelIndex 映射。
3. 对 `history_data.json` 做固定区域热度实验。
4. 加入随机打乱轮盘顺序对照，确认空间信息是否真的有效。
5. 找到候选后，再看最近 10 局、最近 3 局和 2026 年 4/5/6 月数据。
6. 如果空间热区有效，再研究与热门号码结合。
7. 只有当 walk-forward 和均匀度都过关，才考虑进入 `core/`。

第一阶段不要直接做 UI。

## 9. 初步判断

成熟轮盘理论对我们最有帮助的不是某个传统下注系统，而是一个方向：

> 真正可能产生优势的地方，不是递增下注，而是识别非随机偏差；在我们现有数据条件下，最值得验证的是“真实轮盘空间区域偏差”。

因此，新的研究起点应该是：

- 以真实欧洲轮盘顺序作为基础空间。
- 用滚动窗口识别热区、冷区、迁移、反转。
- 用严格 walk-forward 统计验证。
- 与随机空间顺序做对照。
- 优先尝试改进热门号码算法。
- 不要因为少数漂亮局就产品化。
