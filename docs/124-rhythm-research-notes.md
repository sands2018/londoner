# 124 行组节奏研究临时记录

日期：2026-06-03

## 背景

用户实战中的 124 通常不是把行、组混在一起看，而是把行和组分开判断。常见打法是某个行/组连续 2 轮不出后，追 1、2、4 三轮。

目前的问题是：如果根据“打法统计”里最近历史成功率去决定是否追，判断会比较滞后。等看到成功率已经高了再追，往往可能已经进入反转阶段。

## 基线回测

口径：
- 使用整理后的 `history_data.json`
- 第 201 口以后作为押注区统计
- 某个行/组连续 2 轮不出后，下一口开始打 1、2、4 三轮
- 行、组分开统计

裸打结果：

| 方案 | ROI |
|---|---:|
| 组，2 轮不出打 124 | -3.95% |
| 行，2 轮不出打 124 | -2.37% |
| 行+组全部 | -2.56% |

结论：裸打没有优势。

## 关键发现

最近 18 个完成 gap 中，落在 2-4 区间的比例越高，并不一定越好。这个比例高，表面上等价于“打法统计成功率高”，但回测显示这可能已经接近尾声，容易发生反转。

因此，“成功率已经高”更像警戒信号，而不是天然买点。

## 候选提前信号：行 124

定义：

```text
只看行
当前行连续 2 轮不出
打 1,2,4 三轮

条件：
targetRate <= 0.5
trend <= -0.5
mean >= 2
```

特征含义：

```text
targetRate = 最近18个gap里，gap落在2-4的比例
trend = 最近18个gap平均值 - 前18个gap平均值
mean = 最近18个gap平均值
```

直觉：

```text
不是等 2-4 区间已经过热再追；
而是在它尚未过热，同时整体 gap 正在收缩时追。
```

## 组 124 暂不优先

组也能过滤出正收益，但稳定性较弱：

```text
targetRate <= 0.45
trend <= 0.5
longRate >= 0.2
mean >= 2.5
```

结果：

| 指标 | 结果 |
|---|---:|
| ROI | +5.57% |
| 2023 | -65.71% |
| 2025 | +9.09% |
| 2026 | +22.82% |

结论：组不如行可靠，暂时不作为主方向。

## 暂定方向

1. 124 后续优先研究“行”，不要先把行组混合。
2. “打法统计成功率高”可能不是买点，而是过热警戒。
3. 更值得研究的是“未过热 + gap 均值收缩”的提前信号。
4. 下一步如继续，应重点验证行 124 候选信号的最大回撤、最近局表现、单个行拆分，以及最近 12/18/24 个 gap 窗口的稳定性。
