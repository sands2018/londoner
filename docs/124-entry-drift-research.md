# 124 入场轮次漂移研究

日期：2026-06-03
研究：DeepSeek (via Claude Code)
数据：144 sessions, wzs-merged.json, ~35,475 non-zero spins

---

## 背景

用户实战中的124策略：把行、组分开看，某个行/组连续N轮不出后，追1-2-4三轮。

核心问题：**从第几轮开始打？** 传统方法是根据历史成功率决定，但成功率是滞后指标——看到高成功率时往往已经过热，即将反转。

## 研究历程

### 第一阶段：聚合统计过滤（GPT路径）

复现了GPT的初步研究（`124-rhythm-research-notes.md`），用三个条件过滤：
- targetRate ≤ 0.5（最近18gap中2-4占比）
- trend ≤ -0.5（gap均值收缩趋势）
- mean ≥ 2（gap均值不低于2）

**结果**：个体行上GPT-Full最优ROI +9-12%，但信号极少（57-92个/144局）。

**问题**：信号太少，且用户反馈「ROI不够、信号太少」，不是他要的方向。

### 第二阶段：Streak分析

定义「hot streak」：从skip=2入场，124连胜3次以上。

**发现**：
- 每个行/组在最近72局中都有250+次hot streaks
- 平均streak长度5.1次，最长16-17次
- 立即失败率仅8%（92%的情况下至少中一轮）

**关键发现**：所有基于gap聚合统计的特征（均值、方差、趋势、targetRate等）在streak启动时和失败时几乎完全重叠，区分度最大仅0.1个标准差。**gap聚合统计无法预测streak启动。**

### 第三阶段：跨实体热度轮动

分析1行、3行、一组之间的streak轮动。

**发现**：所有轮动方向频率几乎相同（244-253次），间隔几乎相同（~15 spins）。**实体间热度轮动是随机的，不存在可预测模式。**

### 第四阶段：入场轮次漂移（核心发现）

将124机会按相对于streak的位置分为三阶段：
- **Pre-streak**：streak开始前20 spins
- **Mid-streak**：streak进行中
- **Post-streak**：streak结束后20 spins

## 结论：入场轮次漂移规律

**入场轮次随streak生命周期系统性漂移：**

```
冷期(Pre-streak / Neutral):
  → 最优 skip=1 (62%胜率) 或 skip=4 (58%胜率)
  → 绝对避免 skip=2 (仅29%胜率，平均亏4单位)

热期(Mid-streak):
  → 最优 skip=2 或 skip=3 (100%胜率)
  → skip=1 也可以 (86%胜率)

冷却期(Post-streak):
  → 最优 skip=3 (61%胜率) 或 skip=4 (68%胜率)
  → skip=2 崩到41%胜率
```

**核心洞察**：
1. skip=2 是「streak确认器」——如果在streak中，skip=2 100%能赢；如果不在streak中，skip=2是最差的选择
2. 上一把skip=2的结果，就是判断当前处于哪个阶段的最佳指标
3. 不需要任何gap统计、趋势、方差——只需要追踪最近的124结果

## 实战规则草案（待回测验证）

### 阶段判断
- **Cold**：上一把 skip=2 输了，或刚开始尚无记录
- **Warming**：上一把 skip=2 赢了1次
- **Hot**：skip=2 连赢2+次
- **Cooling**：skip=2 刚输（结束了连赢）

### 入场规则
- **Cold → Warming**：等 skip=1 入场（抢跑），或等 skip=4 入场（保守）
- **Warming → Hot**：立即切换到 skip=2 标准入场
- **Hot**：保持 skip=2，直到输
- **Hot → Cooling**：切换到 skip=3 或 skip=4

### 下注规则
- skip=1 入场：用 [1,1,2] 或 [1,2]（短平快）
- skip=2/3 入场：用 [1,2,4]（标准）
- skip=4 入场：用 [2,4]（保守，少轮次高底注）
