# 预测模型详解

两个互补的预测策略，共享 `wave.ts` 波浪分析模块。

---

## 1. 冷门反转

### 原理

当某个行组连续不出超过其历史 92% 分位 + 3 轮缓冲时，属于极端偏离，大概率会回归——押它出现。

### 参数

| 参数 | 值 | 代码位置 |
|---|---|---|
| 统计窗口 | 最近 30 次出现 | `prediction.ts: GAP_WINDOW` |
| 极端分位 | 92% | `prediction.ts: EXTREME_PCT` |
| 缓冲 | 超过阈值 +3 轮 | `prediction.ts: EXTREME_BUFFER` |
| 最少等待 | 6 轮 | `prediction.ts: MIN_GAP` |
| 追号轮数 | 4 轮 | `prediction.ts: CHASE_LENGTH` |
| 翻倍策略 | 1-2-4-8 | `prediction.ts: PROGRESSION` |

### 信号逻辑

1. 对每个行组，取最近 30 个间隔，排序后取 92% 分位作为阈值
2. 当前 gap >= 阈值 + 3 且 >= 6 轮 -> 触发信号
3. 建议 1-2-4-8 翻倍追 4 轮

### 引擎

`ColdReversalEngine`，位于 `prediction.ts`。方法：`analyze(numbers) -> ColdSignal[]`。

无需止损——在历史测试中不设止损效果最好。

### 历史表现

144 组数据（全局）整体 ROI +3.83%，6/7 年份正收益。

## 2. 节奏追号

### 原理

当某个行组的间隔分布出现明显峰值（峰值 +/-1 范围内集中度 >= 65%），说明当前存在稳定节奏——押它继续按这个节奏出。

### 核心特点

- **自适应入场点**：不固定 k=2，而是找当前分布的峰值 k 入场
- **自适应追号长度**：区间宽 2 就追 2 轮，宽 3 就追 3 轮
- **波浪恢复止损**：失败后等 SMA 走完上升->回落周期才恢复，不会永久停
- **默认仅行**：可配置仅报行信号或全部信号

### 参数

| 参数 | 值 | 代码位置 |
|---|---|---|
| 统计窗口 | 最近 18 次出现 | `wave.ts: computePeakStats` windowGaps=18 |
| 峰值范围 | k=1-4 只在这四个值中找峰值 | `prediction.ts` analyzeRhythm() |
| 集中度阈值 | 65%（峰值 +/-1 区间） | `prediction.ts: RHYTHM_MIN_PCT` |
| 追号长度 | 2-3 轮（自适应：区间宽度） | `prediction.ts` analyzeRhythm() |
| 翻倍策略 | 1-2-4（最多到追号长度） | `prediction.ts: RHYTHM_PROG` |
| 止损方式 | 按行组，波浪恢复 | `wave.ts` + App.tsx |
| 波浪上升阈值 | 1.5（SMA 需升高 1.5） | `wave.ts: WAVE_RISE` |
| 波浪最小恢复 | 40 轮（周期太短不采纳） | `wave.ts: WAVE_MIN_RECOVER` |

### 信号逻辑

1. 对每个行组，取最近 18 个间隔，统计 k=1-6 的频次
2. 在 k=1-4 中找频次最高的作为峰值
3. 计算 [峰值-1, 峰值+1] 范围内的集中度
4. 集中度 >= 65% 且当前 gap == 峰值 -> 触发信号
5. 追号长度 = 区间宽度（2 或 3 轮）
6. 翻倍策略 = 1-2-4，只到追号长度

### 波浪恢复（止损后如何恢复）

追号失败后，该行组进入暂停状态，通过波浪分析判断何时恢复：

1. **记录失败时的 SMA**：`failSma` = 最近几个峰值 k 的移动平均
2. **阶段 0 - 等上升**：等待 SMA >= failSma + 1.5（波浪进入上升期）
3. **阶段 1 - 等回落**：等待 SMA <= failSma（波浪完成完整周期）
4. **最小恢复**：整个周期至少 40 轮，不够 40 轮则视为噪音，重置等待下一波
5. **恢复**：满足以上条件后解禁，该行组重新出信号

```
失败(k=3,SMA=2.4) -> 等上升 -> SMA=3.1(>=2.9) -> 等回落 -> SMA=2.3(<=2.4) -> 等了45轮(>=30) -> 解禁!
                                                                      等了15轮(<30) -> 重置等下一波
```

### 波浪模块 (`wave.ts`)

独立的波浪分析模块，可供任何预测算法复用。导出：

- `extractGaps(numbers, ci)` — 提取某个行组的间隔序列
- `computePeakStats(gaps)` -> `{ peak, conc, zoneLen, sma }` — 当前节奏快照
- `computePeakSma(gaps)` — 近期峰值 k 的移动平均（反映波浪趋势）
- `checkWaveRecovery(state, gaps, round)` — 波浪恢复状态机
- `WaveRecoveryState` 类型 — `{ paused, failSma, failRound, phase }`

### 引擎

`RhythmEngine`，位于 `prediction.ts`。方法：`analyze(numbers) -> RhythmSignal[]`。

使用 `wave.ts` 进行峰值检测。恢复逻辑在 `App.tsx` 中（回放历史数据判断当前暂停状态）。

### 历史表现

103 组数据（排除 2026-02 异常月）整体 ROI +6.8%，共 1,804 次信号。所有时段均正收益。

## 信号显示（UI）

两种信号都显示在首页统计面板下方的"预测信号区"：

- **冷门反转**：粉红底，4 个圈（OOOO），点开冷门反转详情窗
- **节奏追号**：绿底，2-3 个圈（OO 或 OOO），点开节奏追号详情窗

每行显示：行组名 + 圈 + 当前押注额。实心圈 = 已完成的追号轮次，空心圈 = 待追轮次。

详情窗显示 ROI 统计表、策略参数栏、每个行组的当前状态。

---

## ROI 追踪

两个策略都有实时 ROI 计算：

- `computeRoi(numbers)` — 冷门反转模拟
- `computeRhythmRoi(numbers)` — 节奏追号模拟

在各自的详情窗中显示：数据量、总投入、总赢回、ROI 百分比。

## 维护须知

调整参数时：
1. 修改 `prediction.ts` 或 `wave.ts` 中的常量
2. UI 文案自动读取导出的常量，无需手动改
3. 用批量模拟脚本对 `sands_history.txt` 跑验证
4. 参数有重大变更时更新本文档
